# VortexMC Store UI

A static, mobile-friendly store UI for VortexMC.

## Included
- Rank cards
- Payment modal
- Placeholder QR
- Placeholder UPI ID
- Discord continuation button
- Responsive mobile design

## Before going live
Replace the placeholder QR and UPI ID with an authorized payment account.
For automatic delivery, connect a real payment provider/webhook and verify payments server-side. Do not treat a payment screenshot as proof of payment.

The current Discord button is only a placeholder (`https://discord.com/`).
